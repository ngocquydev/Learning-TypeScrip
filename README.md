# MÔ TẢ

DỰ ÁN CHỦ YẾU ĐỂ HỌC Typescrip,ReactJS,Nodejs,PgSQL

- express: Khung làm việc (framework) cốt lõi để xây dựng web server và các API endpoint cho backend.
- @clerk/express: Tích hợp xác thực (Auth) của Clerk vào Express, giúp bạn bảo vệ các route API và xác thực token gửi lên từ frontend.
- cors: Middleware giúp bật cơ chế chia sẻ tài nguyên chéo nguồn (CORS), cho phép ứng dụng React của bạn ở cổng khác gọi được API vào backend này.
- dotenv: Nạp các biến môi trường từ file .env vào process.env (như mật khẩu database, cổng server, API keys).
- drizzle-orm: Thư viện ORM giúp bạn thao tác với cơ sở dữ liệu bằng TypeScript một cách an toàn, nhanh gọn và tối ưu hiệu suất.
- pg: Trình điều khiển (driver) chính thức cho Node.js để kết nối và giao tiếp với cơ sở dữ liệu PostgreSQL.

# DevDependencies

- typescript: Bộ biên dịch và cung cấp hệ thống kiểu dữ liệu cho TypeScript.
- ts-node: Cho phép Node.js chạy trực tiếp các file mã nguồn .ts mà không cần dịch thủ công ra file .js trước.
- nodemon: Tự động khởi động lại server mỗi khi bạn chỉnh sửa và lưu file code, giúp quá trình lập trình nhanh hơn.
- drizzle-kit: Bộ công cụ dòng lệnh (CLI) đi kèm với Drizzle ORM, dùng để tạo và quản lý migrations hoặc đẩy thay đổi schema trực tiếp lên database.
- @types/cors, @types/express, @types/pg: Các gói bổ sung kiểu dữ liệu TypeScript cho các thư viện tương ứng để trình soạn thảo (như VS Code) gợi ý code và kiểm tra lỗi chính xác.
